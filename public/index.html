A support chat for your project, trained on your own docs.

Point it at a website or a docs folder, add one script tag, and it answers visitors from your pages, linking the one it used.

$ git clone https://github.com/Kaeden-Martinson/AI-Support-Agent
$ npm run cli -- init my-app --name "My App" --dir ./docs
$ npm run cli -- ingest my-app
$ npm run serve

Can I run it without an API key?
Searched docs: local model, ollama

Yes. Install Ollama, pull a model, and set the provider:

LLM_PROVIDER=ollama
OLLAMA_MODEL=llama3.1:8b

Nothing leaves your machine; answers are a little less sharp than Claude's.

How it answers

Your pages in, cited answers out.

1 · ingest

Crawl or read

Your site, a docs folder, or a README. Respects robots.txt.

2 · index

Split by heading

Passages kept whole, code blocks never cut. One JSON file.

3 · search

Find the passage

Keyword search over your passages. Claude retries with other wording when it misses.

4 · answer

Reply with a link

Streams the answer and links the page it came from.

Embed

One script tag on any site.

It renders in its own Shadow DOM, so your CSS can't break it. Works in plain HTML, Next.js, React, Vue, anything that can add a script.

data-agentWhich agent answers
data-colorYour accent color
data-positionleft or right corner
SupportAgent.ask()Open it from your own button
<script src="https://support.example.com/widget.js"
  data-agent="my-app"
  data-color="#1f6f50" defer></script>
import Script from "next/script";

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        {children}
        <Script src="https://support.example.com/widget.js"
          data-agent="my-app" strategy="afterInteractive" />
      </body>
    </html>
  );
}
import { useEffect } from "react";

export function SupportWidget() {
  useEffect(() => {
    const s = document.createElement("script");
    s.src = "https://support.example.com/widget.js";
    s.dataset.agent = "my-app";
    s.defer = true;
    document.body.appendChild(s);
  }, []);
  return null;
}

Models

Claude by default. Your own GPU when nothing may leave the box.

Claude

  • Searches several times and reasons across pages
  • Best at saying "I couldn't find that" instead of guessing
  • Paid per message; set a rate limit

Ollama, local

  • llama3.1:8b fits an 8 GB GPU
  • No API key, no data leaves your server
  • Fine for direct "how do I" questions; weaker across many pages
